pip install torch transformers accelerate fastapi uvicorn
if the system does not have GPU install below requirement
pip install torch --index-url https://download.pytorch.org/whl/cpu

run the server with this or this
uvicorn --factory inference_server:app --host 0.0.0.0 --port 8080 --reload
or
python -m uvicorn inference_server:app --host 0.0.0.0 --port 8080 --reload
